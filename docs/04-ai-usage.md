# AI 使用范围与个人贡献记录

## 已发生的辅助活动

本版本由候选人向 Codex 提供考核说明与四道题，选择“内容任务规划 Agent”，确认项目路径，并指定 `deepseek-flash` 后，使用 Codex 辅助搭建。

AI 辅助范围：题目比较、初步架构、业务合成数据、Python 代码、模型适配、离线模拟器、状态持久化、错误处理、测试、验收脚本与初版文档。实现和运行记录中有较大比例 AI 辅助内容，应如实说明，不能称为候选人独立从零编写。

本次没有使用子 Agent 或多 Agent；没有使用 LangGraph/ADK 等 Agent 框架。没有将真实密钥输入模型上下文。AI 查阅 DeepSeek 官方接口文档并执行了本地测试；随后在用户配置本地密钥后，实际调用了 DeepSeek，并保存完整真实验收与首轮失败记录。

## 已验证的修改与设计

- 将最初计划中的运行时第三方依赖替换为标准库，降低评审安装成本。
- 为保存步骤加入预算与当前截止时间二次核算，用强行保存、时间推移用例验证。
- 用 SQLite 唯一约束和任务锁处理重复执行，用数据库数量与并发锁用例验证。
- 将模型完成声明与数据库状态绑定，用虚报完成用例验证。
- 区分真实模型、Mock 和模拟 HTTP 协议测试，避免把离线效果写成模型效果。
- 添加跨进程续跑、合成资料变化和接口错误的测试，避免只验证正常路径。

这些工作由 AI 辅助实施并验证，测试事实见 `examples/test-results.txt`。候选人后续修改需另行补记。
